# **ChatGPT Discord Bot**
This is a Discord bot that integrates Azure OpenAI and Azure Search to provide AI-powered responses based on indexed documents. It listens to messages, searches for relevant information and generates responses using OpenAI's chat model.

The bot is trained on documents about binary trees and is designed to help students with their lab assignments. It acts as a virtual teaching assistant, guiding students through problem-solving rather than providing direct and immediate answers.
